# 内容编辑 · content-editor

把素材整理成小红书、Twitter/X、公众号稿件和配图。

## 安装

直接对 Codex 说：

```text
帮我安装这个 Skill：https://github.com/moyi-dong/content-editor
```

## 使用

**1. 生成小红书稿件**

```text
$content-editor 把这篇文章做成小红书稿件，配好图片：[粘贴文章或链接]
```

**2. 生成 Twitter 稿件**

```text
$content-editor 把这篇文章做成 Twitter 稿件，配好图片：[粘贴文章或链接]
```

**3. 继续对话修改**

生成后可以自己改，也可以直接接着说：

```text
标题换成更直接的观点，第二段再短一点，保留原来的例子。
```
