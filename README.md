# 内容编辑 · content-editor

把素材整理成小红书、Twitter/X、公众号稿件和配图。

## 安装

直接对 Codex 说：

```text
帮我安装这个 Skill：https://github.com/moyi-dong/content-editor
```

## 使用

**1. 给链接，生成小红书**

```text
$content-editor 把这篇文章做成小红书稿件和配图：[粘贴链接]
```

**2. 给论文标题，生成 Twitter**

```text
$content-editor 找到并读完《Attention Is All You Need》，生成 Twitter 稿件和配图。
```

**3. 先聊，再生成，再修改**

在同一对话中依次说：

```text
先聊聊这篇文章的观点，暂时不写稿：[粘贴链接或论文标题]
$content-editor 根据刚才的讨论，生成小红书稿件和配图。
第二段再短一点，保留例子。
```
