# 内容编辑 · content-editor

一个以中文指令编写的轻量 Skill：把对话、热点链接、播客和零散想法整理成小红书、Twitter/X、公众号的内容包。默认小红书，也可以一次指定多个平台。

核心规则都在 [SKILL.md](SKILL.md)。没有独立服务或必需的第三方依赖，读取网页、处理图片和校验长度使用运行环境中可用的工具。它能指导内容生产和发布记录，不自带社交平台登录、定时发布或数据抓取服务。

## 试用

在已安装该 Skill 的 Codex 中输入：

```text
$content-editor 把下面这段对话整理成小红书帖子，重点保留我的判断：
（粘贴对话或链接）
```

```text
$content-editor 把这份素材做成小红书、中文 X 串帖和公众号三个版本：
（粘贴素材）
```

```text
$content-editor 这次只给文字，不做图：
（粘贴素材）
```

发布之后，可以告知已发布的平台、对应选题和链接，由 Skill 更新工作区的发布记录。

## 安装

将本仓库克隆或下载到 Codex 的个人 Skill 目录，文件夹命名为 `content-editor`；也可以将已有的本地仓库软链接到该目录。按当前环境使用 `$CODEX_HOME/skills`，未配置时使用 `~/.codex/skills`。

```sh
git clone https://github.com/moyi-dong/content-editor.git "${CODEX_HOME:-$HOME/.codex}/skills/content-editor"
```

若同名目录已存在，请先检查，避免覆盖。安装后若列表未更新，重新打开 Codex 会话。参见 [OpenAI Skill 文档](https://learn.chatgpt.com/docs/build-skills)。

## 默认交付

- 小红书：推荐标题和备选、短正文、相关话题、封面与必要内页。
- X：适合账号长度限制的单帖或串帖。
- 公众号：标题、摘要、正文与封面。
- 工作区文件：每个选题的内容包，以及按平台登记的发布记录。

小红书采用标题20字符、正文500字符的编辑约束，并对粘贴文本计数；X 的长度使用平台加权口径。平台界面是最终校验依据。原文摘录优先于生成内容，缺少来源或图片工具时会明确交付缺口。

用户素材、聊天内容、稿件和发布记录保存在工作区，公开仓库只维护通用 Skill。初版供实际使用迭代，不宣称经过平台自动发布验证。
